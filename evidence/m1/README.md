## 重现步骤

1. 在隔离开发环境安装`tools/requirements-m1.txt`，运行`python3 tools/verify_m1.py`；不会改写人工expected，只输出验证证据。
2. 如需重新制作来源夹具，先提供Artifact Tool的隔离node_modules路径，再运行`tools/build_m1_fixtures.mjs`、`tools/finalize_m1.py`。后者会重建合成来源/规则/答案的清单摘要；必须人工审查diff后再接受新哈希。正常验证不运行构建器或finalize，避免掩盖变化。
3. 用`tools/render_m1_final.mjs`只读渲染输入；渲染后重跑verify确认来源摘要未改。
4. 容量探测按`docs/capacity-policy.md`步骤执行。临时依赖、探测大文件、渲染图和缓存目录都不进入Git。
