## 测试与独立审查

M3.1测试先因matching模块缺失失败，实现后51个测试通过并提交b470c56。M3.2的compare/coverage测试先因compare缺失失败，实现后68个测试通过。随后一次独立只读审查复现8项Important、2项Minor，主Agent按实际影响将一项来源定位防御问题升级Important。以下9项均补失败回归并修复，全套最终77个测试通过：

| 问题 | 修复证据 |
| --- | --- |
| XLSX原生ISO日期经库丢失时区/微秒而误判相等 | 临时真实XLSX t=d夹具先复现错误，再增加date_lexeme只读传递；时区不同不可比，微秒不同有差异。 |
| 非法ISO偏移被规范化、重复格式指令抛re.error | 限定偏移分钟范围，日期格式失败转不可比，不中断其他任务。 |
| 内部表结构引用/字符串被误作外部工作簿 | 忽略双引号字符串并识别实际引用；仍拒绝普通及带引号/横线表名的真实外部引用。 |
| 公共关联入口接受空表/全排除并返回完整 | 输入立即阻断，不制造零字段成功。 |
| 汇总/守恒完成后没有截止复查 | 返回前budget.check；模拟最后阶段已超时必须抛预算异常。 |
| 明细delta可与总额不一致而检查仍通过 | 篡改delta为999、null、NaN均被独立覆盖检查拒绝。 |
| Decimal继承宿主指数上限及trap | 显式独立Context；宿主低Emax、低prec及Inexact/Rounded trap下计算和总额仍正确。 |
| 1904序号0被库读成time而失去日期 | 用可信epoch/数值词法恢复第一天，date/datetime均可与明确文本比较。 |
| 同一表单个单元格混入其他文件/工作表定位 | 统一来源身份校验，混入不同source_id或sheet即拒绝。此项从Minor升级，避免错误回查位置。 |

其他已测范围：重复键两侧全隔离、一对多、规范化碰撞、编号前导零/数值精度风险、null与0、容差边界/负数/高精度差额、币种单位、公式有/无/错误缓存及新鲜度、1900虚构闰日、数值时间亚毫秒缺口、行/字段/排除分区与摘要篡改、多任务来源和预算。
