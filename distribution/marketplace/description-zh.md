# Excel表格核对助手

按业务编号与明确规则核对 Excel 和 CSV，整理字段差异、缺失记录、重复编号和待确认事项，生成可筛选的结果工作簿与可追溯报告。

## 适合处理的任务

- 核对订单与交付记录的数量、金额和业务编号。
- 对照库存台账与盘点表，检查数量、仓位和单位。
- 核对报名、签到和活动名单，查找两侧独有与字段变化。
- 比较两版资产或行政清单，保留原值、差额与原行定位。

## 使用流程

提供文件并明确范围 → 整理业务键和字段规则 → 结构预检 → 精确关联与字段比较 → 生成 Excel、报告和待确认事项 → 回查原表并复核。

支持唯一键和复合键，保留编号前导零；重复键、空键和一对多单独处理，不任意去重或配对。数值比较使用精确十进制，可按明确规则设置容差、单位和币种。公式文本与缓存分开说明，工具不重算公式。

## 实际交付

- 核对结果.xlsx：概览、规则、范围、例外明细、两侧独有、待确认与完整匹配索引。
- 核对报告.md、待确认事项.md：范围、主要差异与需补充的信息。
- 工作资料及交付清单：完整结构化记录、来源定位和文件摘要。

原文件只读，每次生成新版本。结果中的“执行完整”表示指定规则执行完毕，仍可能存在业务差异。

## 运行条件

客户端需具备本地文件读写和 Python 执行能力。Python 3.9+；XLSX 需要 openpyxl>=3.1,<4。CSV 可只用标准库完成核对与 Markdown/JSON 交付；未生成的格式会明确说明。无需额外模型 API 密钥。

标准 Skill 与 WorkBuddy 分别提供安装包。本机 WorkBuddy V5.9.3、Codex CLI 已完成实际调用；其他客户端的本地安装路径见仓库说明，未宣称所有客户端均已实跑。
