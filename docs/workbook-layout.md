# 核对结果工作簿布局 v1

M1布局规格，尚未生成结果样张。案例XLSX是输入测试资料，不是核对报告UI。

## 阅读路径

打开“核对概览”先看范围、完成状态和待确认数量，再通过内部导航进入差异与原行定位。背景白色，主色深蓝`#17365D`，浅蓝`#EAF2FB`辅助分组，正文`#243247`。差异用浅红与“有差异”，歧义用浅琥珀与具体原因，正常记录不大面积涂绿。字体优先可用的办公字体，正文11pt，标题16pt；中文显示需在目标办公软件复核。

| 工作表 | 内容和字段 | 交互 |
| --- | --- | --- |
| 核对概览 | A2标题，A4任务/状态，A6来源与选择范围，A10起逐任务逐侧数量表，之后字段状态表与限制。显示selected/included/excluded、四种关联数量、唯一匹配对数、差异/不可比记录数及字段分母。不用一个绿色“通过”遮盖范围缺口。 | 内部工作表导航、状态文本、紧凑留白；不冻结小概览。 |
| 字段与规则 | 任务、基准/比较表、原范围、键、左右原列/表头、类型、规范化、容差、单位/币种与公式策略、规则版本及来源摘要。 | 表头筛选，冻结首行和任务列。 |
| 差异明细 | 任务、字段状态、键、字段、基准值、比较值、差额、上下文、规则/原因、两侧文件ID/工作表/原行/列。包含different、within_rule和not_comparable，允许筛选到纯业务差异。 | 文字与状态填色，冻结首行和前4列；来源文本不成为公式或超链接。 |

## 导出与容量

明细无合并单元格。首行表头高30px，正文默认24px，需要时换行并增高。ID列按文本，数量/金额各自保留精度，不统一强制两位；精确十进制文本在内部资料保留，超过Excel数值精度的结果在XLSX按文本并注明。长原值采用换行，不截断。建议列宽：任务16、状态16、键24、字段18、原值28、差额18、原因36、来源ID18、行10、列8；后续按样张视觉检查调整。

单工作表20,000条数据记录分片，如“差异明细_01”“差异明细_02”。只创建有内容的明细表，无内容类别在概览写0。概览导航列出所有分片及条数。完整输出预算由[规则协议](rules-protocol.md)统一管理；超限时XLSX整体未生成，不悄悄只放前N行。

默认包含全量匹配索引；逐字段完整结果写`工作资料/字段结果.jsonl`，逐源行关联状态写`工作资料/关联结果.jsonl`。哈希与实际状态列在交付清单。摘要、索引、字段明细三者数量不一致时禁止标记完成。

## M4视觉验收

检查中文无方框、表头不截字、前导零/长编号完整、负差额方向、颜色与文本一致、筛选/冻结/分片导航有效。必须用实际Excel或WPS打开检查并保存证据；库回读、图片渲染和XML检查分别记录，不能互相替代。该阶段尚未执行。
