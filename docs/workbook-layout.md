# 核对结果工作簿布局 v1

M4已实现本布局，并保存[文件与办公验收证据](../evidence/m4/README.md)。examples目录的XLSX仍是输入测试资料，输出样张在忽略目录outputs中。

## 阅读路径

打开“核对概览”先看范围、完成状态和待确认数量，再通过内部导航进入差异与原行定位。背景白色，主色深蓝`#17365D`，浅蓝`#EAF2FB`辅助分组，正文`#243247`。差异用浅红与“有差异”，歧义用浅琥珀与具体原因，正常记录不大面积涂绿。字体优先可用的办公字体，正文11pt，标题16pt；中文显示需在目标办公软件复核。

| 差异明细 | 任务、字段状态、键、字段、基准值、比较值、差额、上下文、规则/原因、两侧文件ID/工作表/原行/列。包含different、within_rule和not_comparable，允许筛选到纯业务差异。 | 文字与状态填色，冻结首行和前4列；来源文本不成为公式或超链接。 |

## 导出与容量

明细无合并单元格。表头34pt，正文按列宽、中文宽度和显式换行估算28–120pt，原值宽27、原因/上下文36、来源行列16，85%缩放。字体标记Microsoft YaHei，正文11pt、标题16pt；目标软件的字体回退和显示需实看。所有任务标签包含稳定任务ID，避免同一对表的不同规则混淆。

ID列按文本，数量/金额各自保留精度，不统一强制两位；精确十进制文本在内部资料保留，超过Excel可靠精度的结果按文本。原日期优先展示ISO源词法或明确标注Excel日期序号。长原值换行并保留完整单元格，极长文本超出显示高度时可用编辑栏/工作资料查看；不把显示高度限制变成数据截断。

单工作表20,000条数据记录分片，如“差异明细_01”“差异明细_02”。只创建有内容的明细表，无内容类别在概览写0。概览导航列出所有分片及条数。完整输出预算由[规则协议](rules-protocol.md)统一管理；超限时XLSX整体未生成，不悄悄只放前N行。

默认包含全量匹配索引；逐字段完整结果写`工作资料/字段结果.jsonl`，逐源行关联状态写`工作资料/关联结果.jsonl`。哈希与实际状态列在交付清单。摘要、索引、字段明细三者数量不一致时禁止标记完成。

已在macOS WPS检查中文无方框、表头、前导零/长编号、颜色与文字、状态筛选、横向冻结和公式样式原文。分片条数/唯一结果ID/导航位置由真实文件回读检查；本机办公证据与库验证分别记录。跨设备/系统显示、负差额的真实办公样张及最大复杂表性能留待M6；不以本次小样声称全部容量通过。
