## 发布建议（未执行）

建议先以免费Skill在WorkBuddy完成提审，审核后再公开GitHub；SkillHub作为后续独立渠道。若选择开源，建议考虑[MIT许可证](https://opensource.org/license/mit)：它允许使用、修改、分发和商业使用，分发时需保留版权及许可声明。是否接受这些授权由作者决定，当前不创建LICENSE文件、不宣称已经MIT开源。

若选择为下载包内补入LICENSE或其他资源，应在确认后生成新的发布版本并重新验包，保留当前0.1.0双包不覆盖。仅上传外部平台Logo或修改市场展示信息不等于修改Skill引擎。

## WorkBuddy提审步骤（待授权后执行）

1. 复核最终许可、版本、介绍、示例、Logo与包摘要。
2. 打开WorkBuddy开放平台的技能创建入口，上传对应平台ZIP，等待解析结果。
3. 核对中英文展示名、介绍与等长非空示例，上传已审阅Logo；分类按实际页面可选项确定。
4. 查看平台风险/错误提示及具体上传要求，不自动改权限、接受协议或跳过校验。
5. 用户授权后提交审核，保存回执；分别记录“已上传并解析”“已提交”“审核通过”“市场已上线”。

当前字段依据[WorkBuddy官方技能文档](https://open.workbuddy.cn/docs/skill)：标准name、展示名、中英介绍、作者、版本与中英示例。官方说明中的示例对应详情页“试试这样用”；README图片不会自动变成市场图文案例展示。当前尚未确认自助图文案例编辑入口。
