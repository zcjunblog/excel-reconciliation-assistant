# 解释器、依赖与宿主能力

使用本机/宿主真实提供的Python3.9+，不要假设`python`、`python3`或某台开发机路径必然可用。脚本和模板从本技能目录定位，业务资料与输出放工作区。所有命令按独立参数传递，对含空格的路径正确引用。

`doctor.py`只检查当前解释器、技能版本、必要资源和openpyxl能力。默认CSV可用即可就绪；`--require-xlsx`要求Excel读取/输出依赖也可用。能力检查不等于已核对业务文件。

- CSV读取、十进制比较、MD/JSON/JSONL：标准库。
- XLSX读取/输出：同一个解释器中的`openpyxl>=3.1,<4`。
- 不需要模型API密钥、桌面Excel/WPS、网络账号、开发机字体或特定客户端工具名。

缺少Excel依赖时，先检查工作区已有虚拟环境或宿主提供的解释器。需要安装时仅在已获授权的项目环境中，用该环境的Python执行`-m pip install -r <skill_dir>/requirements.txt`；不安装到全局或自动修改客户端配置。

无法获得Excel依赖：XLSX来源阻断；CSV仍可核对并生成完整MD/JSON，Excel实际未生成，整批partial。没有文件执行能力的聊天客户端只能讨论已提供内容，不能声称扫描了未读文件或产生了附件。

运行失败时保留stdout错误代码和解释器版本，按实际原因修正。不要通过更改原表、静默截断、忽略非零退出码或把MD改后缀来制造Excel。
